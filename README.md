# ABBAS AGRO FARM - Modern Organic Farming Website

## Project Overview

This is a modern, responsive website for **ABBAS AGRO FARM**, an organic farming business located in Khashkarara Union, Chuadanga, Khulna Division, Bangladesh. The website showcases organic products, services, and promotes sustainable farming practices with community engagement.

## Features

### Core Features
- **Responsive Design**: Mobile-first approach with full responsiveness across all devices
- **Bilingual Support**: Bengali and English language toggle functionality
- **Modern UI/UX**: Clean, minimalist design with earthy color scheme
- **SEO Optimized**: Meta tags, structured data, and local search optimization
- **Fast Loading**: Optimized CSS, JavaScript, and lazy loading for images

### Sections
1. **Home**: Hero section with call-to-action buttons
2. **About Us**: Farm story, mission, and key features
3. **Products**: Organic crops, vegetables, fruits, and livestock
4. **Services**: Farm consulting, training, B2B partnerships, and more
5. **Gallery**: Visual showcase of farm activities and products
6. **Blog**: Educational content and farming insights
7. **Contact**: Contact form, location details, and embedded Google Maps

### Interactive Features
- **Language Toggle**: Switch between English and Bengali
- **Testimonial Carousel**: Customer reviews with auto-rotation
- **Smooth Scrolling**: Enhanced navigation experience
- **Contact Forms**: Newsletter subscription and contact form with validation
- **WhatsApp Integration**: Floating WhatsApp button for instant communication
- **Back to Top**: Smooth scroll to top functionality
- **Scroll Animations**: Intersection Observer API for smooth reveals

## Technology Stack

- **HTML5**: Semantic markup with proper structure
- **CSS3**: Modern CSS with CSS Grid, Flexbox, and CSS Variables
- **Vanilla JavaScript**: No dependencies, pure JavaScript implementation
- **Google Fonts**: Poppins font family for clean typography
- **Font Awesome**: Icons for enhanced visual appeal
- **Google Maps**: Embedded location map

## Setup Instructions

### 1. Clone or Download
Download the project files to your local machine.

### 2. Add Images
Place the following images in the `images/` folder:
- `logo.png` - Farm logo (40x40px recommended)
- `farm-overview.jpg` - Main farm overview image
- `rice-field.jpg` - Organic rice field photo
- `vegetables.jpg` - Fresh vegetables photo
- `livestock.jpg` - Farm animals photo
- `harvest.jpg` - Harvest season photo
- `farmers.jpg` - Farmers working photo
- `training.jpg` - Training session photo
- `blog1.jpg` - Blog post 1 image
- `blog2.jpg` - Blog post 2 image
- `blog3.jpg` - Blog post 3 image

### 3. Local Development
1. Open `index.html` in a modern web browser
2. For best results, serve through a local web server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using PHP
   php -S localhost:8000
   
   # Using Node.js (with http-server)
   npx http-server
   ```

### 4. Customization

#### Contact Information
Update the contact details in `index.html`:
- Phone numbers (replace `+৮৮০ ১৭XX XXX XXX`)
- Email addresses
- WhatsApp number in the floating button and contact section

#### Google Maps
Update the Google Maps embed URL in the contact section with the actual coordinates of the farm location.

#### Content
Modify the text content in both Bengali and English by updating the `data-en` and `data-bn` attributes in the HTML.
